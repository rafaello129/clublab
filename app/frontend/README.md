# Frontend

Aplicación SPA de ClubLab.

## Stack previsto

```text
React
TypeScript
Vite
React Router
```

## Vistas

```text
/login
/dashboard
/ranking
/missions
/team
/activity
/profile
```

## Reglas pedagógicas

- Las requests REST deben ser visibles en DevTools.
- No usar Service Worker, GraphQL ni polling en v1.
- Un error de ranking no debe romper el resto de la UI.
- No habrá una UI para editar el score; M4 ocurre desde PostgreSQL.
- Assets locales para que el laboratorio funcione sin Internet.

La implementación comenzará después de cerrar la capa operativa.
